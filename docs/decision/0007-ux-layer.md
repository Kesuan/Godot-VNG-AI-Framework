# 0007 · 体验层（设置 / 已读 / 跳过 / 自动 / 回顾）

- 状态：已接受
- 日期：2026-10-14
- 关联决策：[0001](0001-testing-strategy-v1.md)、[0003](0003-game-project-structure.md)、[0004](0004-presentation-testing.md)、[0006](0006-multi-chapter-and-save.md)

## 背景

多章节与存档落地后，长内容试玩暴露出 VNG 基础体验缺口：不能调文字速度与音量、重复内容无法快进、无法自动播放、不能回看已读对白。这些能力同时影响用户试玩效率与后续配音管线（已读/语音都需要稳定的"行 ID"）。

## 决策

### 1. 设置存储（VngSettings）

- 位置 `game/services/settings_store.gd`；JSON 持久化，默认 `user://settings.json`（测试可注入路径）；
- 字段：`bgm_volume` / `sfx_volume`（0–1）、`text_speed`（字/秒，`<= 0` = 瞬间）、`auto_delay`（行完整显示后的等待秒数）；
- 与存档分离（设置跨存档全局有效）；文件损坏/缺字段回退默认值并静默解析；越界值夹取；
- 改动即刻写入并即时生效（音量应用到 `AudioDirector`，文字速度应用到打字机）。

### 2. 已读记录（VngReadLog）

- 位置 `game/services/read_log.gd`；按 `story_hash` 隔离，持久化 `user://read/<story_hash>.json`；
- **行 ID 采用内容哈希**：`sha256(who + "\n" + text.strip_edges())` —— 文本改动即视为未读，插入/重排不漂移；
- 显示即标记（对白与旁白，含读档重绘的行）；容量上限 5000，超限丢弃最旧；
- 行 ID 方案与后续配音管线（TTS 内容寻址）天然兼容。

### 3. 跳过已读

- 触发：按住 `Ctrl` 或按住底栏「跳过」按钮；松开即停；
- 只跳过**已读**行；遇未读行 / 选项 / 菜单 / 回顾 / 设置即停；
- 打字中的已读行先补全再推进。

### 4. 自动播放

- 触发：`A` 或底栏「自动」开关（按钮高亮表示开启）；
- 行完整显示后等待 `auto_delay` 再推进；选项处停下（选择后恢复）；
- 与跳过同时触发时跳过优先。

### 5. 回顾（backlog）

- 触发：`B`、底栏「回顾」或面板关闭键；
- 记录**本次会话（跨章）**：对白 / 旁白 / 选项选择 / 章节分隔；上限 400 条，超出丢最旧；
- 面板可滚动、打开时自动滚到底；**不持久化**（重启清空）。

### 6. 输入与入口约定

- 动作 `vng_skip` / `vng_auto` / `vng_backlog` 由表现层运行时注册（`story_screen.ensure_input_actions()`），不写进 `project.godot`；测试用 `InputEventAction` 直接驱动；
- 底栏按钮（回顾 / 自动 / 跳过）与快捷键并行，鼠标与键盘等价；
- 设置入口：标题屏「设置」+ 游戏内 ESC 菜单「设置」；面板即时生效并持久化。

## 后果

- 试玩长内容不再需要重复点击已读文本；改剧本后只有**文本变化**的行重新变为未读；
- 行 ID 成为"已读 / 语音 / 未来跳过已读配音"的公共主键，配音管线可直接复用；
- 回顾不持久化、无"跳到下一选项"专用模式，属于当前有意边界，按需再扩展。

## 被否决方案

| 方案 | 否决原因 |
| --- | --- |
| 位置型行 ID（`chapter.node.index`） | 插入/重排台词后漂移，已读记录错位 |
| 设置并入存档 | 设置应跨存档全局生效 |
| 回顾持久化到 `user://` | 容量与清理策略成本高，V1 无刚需 |
| 输入动作写进 `project.godot` | 框架/游戏两侧需同步维护，测试注入更繁琐；运行时注册即可 |
